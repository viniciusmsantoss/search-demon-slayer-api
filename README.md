# SearchDemonSlayerAPI — Consulta de Personagens (.NET Blazor WASM)

Aplicação Web desenvolvida em **Blazor WebAssembly** em **.NET 10** para listagem e busca dinâmica de personagens da API do universo **Demon Slayer**.

## 🚀 Funcionalidades

- Listagem de personagens consumidos do endpoint paginado da API pública.
- Filtro/busca em tempo real pelo nome do personagem (ex: *Tanjiro Kamado*, *Nezuko Kamado*, *Giyu Tomioka*).
- Exibição detalhada em cartões com:
  - **Nome** (`name`)
  - **Idade** (`age`)
  - **Raça** (`race`)
  - **Frase marcante / Citação** (`quote`)
  - **Imagem** (`img`)
